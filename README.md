# Crispy Satisfied Website
Responsive static website starter. Open `index.html` to preview.

## Deploy free with GitHub + Vercel
1. Create a GitHub repository and upload `index.html`, `styles.css`, `app.js`, and `menu.js`.
2. In Vercel, choose **Add New → Project**, import the repository, and deploy with the default static settings.
3. Connect a custom domain later if desired.

## Edit menu
Edit `menu.js`. Each entry is `["Item name", price, "veg"]` or `["Item name", price, "nonveg"]`.
